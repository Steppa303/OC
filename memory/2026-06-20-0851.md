### 📋 User‑Workflow (Schritt für Schritt)

1. **App öffnen** → Man landet auf dem Bücherregal (Shelf View). Entweder leer mit Upload‑Aufforderung oder gefüllt mit Buch‑Cover‑Karten.  
2. **EPUB hochladen** – Drag & Drop oder Klick auf die Dropzone (nur .epub erlaubt). Während des Uploads erscheint ein Fortschrittsbalken; bei Erfolg erscheint das Buch sofort im Regal (Cover aus EPUB oder generiert, Titel/Autor aus Metadaten, Fortschritt 0 %).  
3. **Buch lesen** – Klick auf das Cover öffnet die Reader‑View:  
   - Kapitel werden geladen, man landet automatisch an der letzten Position (Lesezeichen).  
   - Oberhalb des Textes: Fortschrittsbalken (%).  
   - Sidebar (📋) zeigt das Inhaltsverzeichnis, klickt man ein Kapitel → Sprung dorthin.  
   - Lesezeichen setzen (🔖) – speichert Kapitel + Scroll‑Position, wird beim nächsten Öffnen wiederhergestellt.  
   - Font‑Größe über A‑ / A+‑Buttons anpassbar (14‑28 px, 2‑px‑Schritte).  
   - Tastatur: ← → für vorheriges/nächstes Kapitel, Leertaste zum Vorlesen‑Start/Pause, Escape zurück ins Regal.  
4. **Vorlesen lassen (TTS)** – Klick auf ▶ (oder Leertaste) startet das ElevenLabs‑Streaming:  
   - Player ist stets sichtbar (unterer Rand).  
   - 6 Stimmen verfügbar (Sarah EN, Thomas DE, Berta Berlin DE, Nervbold DE [toxisch], Roger EN, Charlie EN).  
   - Speed‑Regler (Desktop) bzw. Preset‑Buttons (Mobile) von 0,5× bis 2,0×.  
   - Auto‑Advance: nach Kapitel‑Ende 3‑Sekunden‑Countdown → automatischer Sprung zum nächsten Kapitel.  
   - Bei Buch‑Ende: Overlay „Buch beendet!“ mit Option zum Neustart oder Rückkehr zum Regal.  
   - Fehler‑Handling: rote Retry‑Leiste unter dem Player, verschwindet nach 4 s automatisch.  
5. **Theme umschalten** – Klick auf 🌙/☀️ im Header toggelt zwischen Dark‑ und Light‑Modus (speichert in localStorage, System‑Preference als Default).  
6. **Bücher verwalten** – Suchleiste erscheint sobald mindestens ein Buch vorhanden ist (filtert Titel & Autor in Echtzeit). Jede Buchkarte zeigt den gelesenen Prozent‑Fortschritt an. Löschen derzeit nur über API möglich (`DELETE /api/books/:id`).

### 🎨 Design‑Philosophie

- **Kein AI‑Watermark** – „No AI watermarks, no ‘created with’ nonsense.“  
- **Dark first** – Dark Mode primär, Light sekundär  
- **Glassmorphism** – moderne, leicht transparente UI‑Elemente  
- **Always visible Player** – TTS‑Player klebt am unteren Rand, immer erreichbar  
- **Responsive ab 375 px** – iPhone SE als Minimum  
- **Schnelle Feedback‑Loops** – Toasts für Erfolg/Fehler, Spinner für Loading  
- **Deutsches UI** – Deutsch als Hauptsprache (mit wenigen englischen Überbleibseln)

### 📊 Datenfluss (User‑Perspektive)

```
User öffnet reader.steppa.online
    │
    ├── App lädt Bücherliste (GET /api/books)
    │   ├── Bücher da? → Cover‑Grid anzeigen
    │   └── Keine Bücher? → „Lade EPUB hoch!“
    │
    ├── User lädt EPUB hoch (POST /api/upload)
    │   ├── Server parsed EPUB (AdmZip + JSDOM)
    │   ├── Speichert EPUB + Metadaten in DB
    │   └── Gibt Buch zurück → erscheint im Regal
    │
    ├── User klickt auf Buch (GET /api/books/:id/content)
    │   ├── Server parsed EPUB erneut (Kapitel‑Texte)
    │   ├── Lädt Lesezeichen (GET /api/bookmarks/:id)
    │   └── Zeigt Kapitel + letzte Position
    │
    ├── User liest/blättert
    │   ├── ← → Tasten oder Buttons für Kapitel
    │   ├── Auto‑Save alle 2s (POST /api/bookmarks/:id)
    │   └── Manuelles Bookmark per Button
    │
    └── User startet Vorlesen (POST /api/books/:id/tts)
        ├── Server holt Audio von ElevenLabs (Streaming)
        ├── Browser spielt chunkweise ab
        ├── Speed, Stimme, Auto‑Advance steuerbar
        └── Bei Ende: Countdown → nächstes Kapitel
```

### 🚫 Was die App NICHT ist (und auch nicht sein will)

- ❌ **Kein Kindle‑Ersatz** – kein Einkauf, kein DRM, kein Cloud‑Sync  
- ❌ **Kein PDF‑Reader** – EPUB‑only  
- ❌ **Kein Audio‑Player** – TTS ist zum Vorlesen, nicht zum Musik hören  
- ❌ **Kein Social Network** – keine Bewertungen, keine Kommentare  
- ❌ **Kein Calibre** – keine Metadaten‑Bearbeitung, keine Konvertierung  
- ❌ **Kein Multi‑User** – ein Regal für eine Person  
- ❌ **Keine Offline‑App** – benötigt Internet (für ElevenLabs + EPUB‑Load)
