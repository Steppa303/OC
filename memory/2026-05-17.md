## ~02:50 – SMB Share „clawshare" eingerichtet

### Problem
- Bastian will einen Ordner auf dem VPS als Netzlaufwerk im Heimnetz freigeben
- Zugriff muss über WireGuard (wg0) zur Fritzbox routed werden

### Lösung
- **Samba installiert** (`apt-get install samba`)
- **Share erstellt:** `/srv/clawshare`
- **User angelegt:** `steppa` (System-User, smbpasswd gesetzt)
- **Samba Config:** `/etc/samba/smb.conf`
  - Nur SMB3, kein Guest-Zugriff
  - Bindet an `wg0` + `lo` Interfaces
- **Firewall:** iptables-Regeln – Ports 139/445 nur über `wg0` erlaubt, öffentliche IP blockiert
- **Rules persistent:** `/etc/iptables/rules.v4`

### Status
- ✅ `smbd` running + enabled
- ✅ Share `clawshare` verfügbar unter `//192.168.178.204/clawshare`
- ✅ Schreibtest erfolgreich
- ✅ Firewall-Regeln aktiv + gespeichert
