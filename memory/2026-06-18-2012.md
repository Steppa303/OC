## 📋 Plan: `apps.steppa.online` – Auto-Update Project Index

### Ist-Zustand
Es gibt bereits `apps.steppa.online` mit einer React-App (`/var/www/apps/apps-index/`), aber die ist **statisch gebaut** – muss manuell neu gebaut werden wenn sich was ändert. Außerdem fehlen die Hälfte der Projekte.

### Vorgeschlagene Lösung

**Ein Script + ein HTML-Template**, das den Caddyfile parst und daraus eine statische HTML-Seite generiert. Kein React-Overhead, kein Build-Schritt. Einfach, schnell, funktional.

**Warum Caddyfile als Source of Truth?**
- Alle Projekte sind dort definiert (Subdomains + Pfad-Routen)
- Wenn ein Projekt hinzugefügt/entfernt wird → Caddyfile wird eh geändert
- Script kann als Hook nach jedem Caddyfile-Edit laufen (oder via Cron)

### Architektur

```
scripts/generate-apps-index.sh
├── Parst /etc/caddy/Caddyfile
├── Extrahiert alle Subdomains + Pfade
├── Generiert HTML mit embedded CSS (kein Build nötig)
├── Schreibt nach /var/www/apps/apps-index/index.html
└── Optional: Caddy reload als Post-Hook
```

**Auto-Update via Cron:** Alle 5 Minuten prüfen ob sich der Caddyfile geändert hat (md5sum), wenn ja → neu generieren.

### Design
- Dunkel, minimalistisch (Dark Background, helle Karten)
- Karten mit Projektname, URL, ggf. Beschreibung
- Responsive (Mobile-Ready)
- Kein JavaScript-Framework – reines HTML + CSS + minimales Vanilla JS für Filter/Suche
- Favicon von steppa.online

### Was das Script NICHT macht
- Keine Docker-Container erkennen (keine vorhanden)
- Keine manuellen Port-Services (außer sie stehen im Caddyfile)
- Caddyfile bleibt die einzige Quelle der Wahrheit
