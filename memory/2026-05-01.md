# Daily Memory: 2026-05-01

## MIDI Scraper Projekt

### Projekt erstellt & gestartet (2026-05-01 ~10:00)
- **Pfad:** `/root/.openclaw/workspace/projects/midi-scraper/`
- **12 Python-Dateien, 2171 Lines** via Orchestrator-Subagent erstellt
- **Dependencies:** `mido`, `aiohttp`, `beautifulsoup4`, `aiosignal`, `frozenlist`, `multidict`, `yarl`, `attrs`, `tqdm`, `pyyaml`

### Fixes während der Laufzeit:
1. **YAML Syntax Error** (Session `mild-dai`): `blacklist_extensions` war falsch unter `blacklist_domains` genestet → gefixt
2. **`tqdm.gather` AttributeError** (Session `nimble-p`): `tqdm.gather` existiert nicht → ersetzt durch `asyncio.gather` + manuelle tqdm Progress Bar
3. **Retry Logic Optimiert**: Size-Validation Errors (zu kleine Dateien) werfen jetzt `ValueError` statt `TimeoutError` → keine sinnlosen Retries für 0-Byte/Ringtone-Dateien
4. **Google Search deaktiviert**: Google blockiert automatisierte Requests → 0 Ergebnisse, in config.yaml `google_search.enabled: false` gesetzt

### Scraper Session `tender-ridge` (laufend seit ~10:20)
- **20.570 MIDI-Links** aus Seed-URL-Crawling gefunden
- **Seed-URLs:** 19 Sources (vgmusic.com, MIDI-Besammlung, freepats.com, MIDIWorld, etc.)
- **Viele tote Links:** DNS-Fehler, SSL-Errors, 404s (huge-midi.com, midi-archive.com, onlinesequencer.net, github repos, angelfire.com)
- **vgmusic.com:** Mostly tiny ringtones (< 1KB) → werden gefiltert

### Fortschritt (Stand ~11:40):
- **~15.129 von 20.160 URLs verarbeitet** (~75%)
- **Speed:** ~4.7 files/sec
- **Laufzeit:** ~53 Minuten
- **ETA:** ~16 Minuten bis fertig

### Nächste Schritte (nach Download-Abschluss):
1. `python main.py validate` – MIDI-Dateien validieren
2. `python main.py organize` – Nach Genre sortieren
3. `python main.py index` – metadata.json generieren
4. `python main.py stats` – finale Statistiken

### Config Details:
- **Rate Limiting:** 1.5s Delay zwischen Requests
- **Parallel Downloads:** 8 gleichzeitig
- **Max Retries:** 5 mit exponential backoff
- **Min File Size:** 500 Bytes (filtert Ringtones)
- **Genres:** techno, trance, house, edm, hardstyle, hardcore, dubstep, dnb, ambient, industrial, idm-experimental, electro
