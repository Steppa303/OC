### Lessons Learned MicroPython
- Kein `webrepl`-Modul → Eigenen Server bauen
- Base64-Transfer über TCP ist broken (chr()-Escape-Probleme)
- `sys.stdout` Capture auf Socket funktioniert nicht sauber
- `eval()` + `exec()` im Dual-Protokoll ist der beste Ansatz
- Zeilenweises `f.write()` im REPL (per USB) ist zuverlässigster Weg zum Datei-Editieren
- **Dateistruktur für Stabilität:** `remote.py` (WLAN+Server, tabu) + `quantizer.py` (Logik) + `sketch.py` (Boot+Loop)
