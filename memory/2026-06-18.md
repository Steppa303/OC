
## Usenet Media Pipeline — Implementierung (20:17 - 21:26)

### Was passiert ist:
- Bastian wollte Usenet-basierte Media Pipeline
- Docker installiert (war nicht vorhanden)
- 6 Container deployt: NZBHydra2, NZBIndex Adapter, SABnzbd, Sonarr, Radarr, Jellyfin
- Kostenlose Indexer (BinSearch, NZBIndex, AniZB) waren alle kaputt
- Custom NZBIndex Adapter geschrieben (Python, JSON→Newznab XML)
- NZBGeek API Key von Bastian bekommen → als Primary Indexer konfiguriert
- 4.437 Suchergebnisse für "breaking bad" (NZBGeek: 3.576 + NZBIndex: 861)
- Sonarr/Radarr mit NZBHydra2 + SABnzbd verbunden
- Jellyfin Libraries eingerichtet (Movies + TV Shows)
- Komplette Doku + Handover erstellt

### Lessons Learned:
- NZBHydra2 v8.x hat andere Enum-Werte: TVDB nicht TVDBID, IMDB nicht IMDBID
- NZBHydra2 API Config-PUT persistiert nicht immer in YAML → besser YAML direkt editieren
- NZBHydra2 API Key ändert sich bei manchen Config-Änderungen
- NZBIndex hat neue JSON-API, nicht mehr Newznab-kompatibel
- SABnzbd host_whitelist muss Container-Namen enthalten
