### Lessons Learned:
1. `bot/close` API call clears all getUpdates conflicts on Telegram side
2. Watchdog should check health endpoint, not log timestamps (polling is silent)
3. `systemctl --user restart` from cron needs XDG_RUNTIME_DIR or use kill + auto-restart
