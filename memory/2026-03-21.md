## 🔧 Caddy Deployment Pattern
- **WICHTIG:** Immer `uri strip_prefix` VOR `root` für Subfolder-Deployments
- **Template:**
  ```caddy
  handle /appname/* {
      uri strip_prefix /appname
      root * /var/www/apps/appname/dist
      try_files {uri} /index.html
      file_server
  }
  ```
